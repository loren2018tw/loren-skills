# 分析層規格

第四層到第十二層的格式與範例。概念透析模板與標準輸出格式見 `SKILL.md`；資訊分級、風格與自檢問題見 `style-rules.md`。

## 第四層：重要概念對比

如果教材中存在容易混淆的概念，主動建立比較表：

| 比較項目 | 概念 A | 概念 B |
| -------- | ------ | ------ |
| 定義     | …      | …      |
| 判斷標準 | …      | …      |
| 範圍     | …      | …      |
| 條件     | …      | …      |
| 關鍵字   | …      | …      |
| 常見陷阱 | …      | …      |

優先尋找以下類型：

- A vs B
- 廣義 vs 狹義
- 原因 vs 結果
- 權利 vs 義務
- 身分 vs 能力
- 事實 vs 價值
- 不同年齡門檻
- 不同資格條件
- 不同制度
- 不同法律規範

沒有真正需要比較的概念時，不要為了格式而硬做表格。

## 第五層：考題辨識法

教材透析不能只說明「這是什麼」，必須進一步說明「題目怎麼讓我認出它？」，建立三種對應：

**關鍵字 → 概念**：

```text
蒐集資料
+
比較不同來源
+
分析不同觀點
↓
理性思考批判
```

**情境 → 概念**：

```text
縮小城鄉資源差距
↓
捍衛公平正義
```

**行為目的 → 概念**：

```text
參加社區志工
↓
可能是參與公共事務
```

```text
與不同意見者溝通
↓
和平尊重包容
```

```text
查證網路資訊
↓
理性思考批判
```

特別提醒：不要只看表面行為，要看行為的目的、條件與情境。

## 第六層：案例透析

教材中出現人物、故事、新聞、歷史事件、社會事件、生活情境、圖片案例時，不要只做人物或事件摘要，應拆成：

```text
案例
 ↓
發生什麼事？
 ↓
涉及什麼概念？
 ↓
為什麼？
 ↓
可能考什麼？
```

例如：

```text
某人物原本不是本國國民
 ↓
依法申請歸化
 ↓
取得本國國籍
 ↓
考點：國籍取得方式
```

同一案例同時涉及多個概念時，應全部列出重要考點。

## 第七層：題目解題邏輯

教材附有選擇題、填充題、問答題或參考答案時，不要只列答案，應分析：

- 題目問什麼？
- 題目要求判斷什麼？
- 解題需要哪些條件？
- 題目提供哪些線索？
- 每個選項代表什麼？
- 哪個選項符合條件？
- 其他選項為什麼不符合？

例如：

```text
題目：誰與某人物取得國籍的方式相同？

第一步：找出題幹人物的取得方式
↓
歸化

第二步：檢查選項
↓
出生時父母具有本國國籍 → 出生取得 → 排除
出生時父母皆非本國國民 → 後來取得國籍 → 可能符合歸化
```

教材本身已提供答案時，應以教材內容為主要依據；沒有必要時不要自行改變教材答案。

## 第八層：易混淆觀念與陷阱

每一章主動找出容易錯的地方，至少整理 3～5 個重要陷阱。

格式：

- **陷阱一**
  - 錯誤理解：…
  - 正確理解：…
  - 為什麼容易錯：…

優先注意：

- 相似名詞
- 廣義／狹義
- 不同年齡
- 不同資格
- 不同數字
- 權利／義務
- 原因／結果
- 「可以」／「必須」
- 「可能」／「一定」
- 「部分」／「全部」
- 「主要」／「唯一」

教材沒有足夠資訊支持某個陷阱時，不要硬湊。

## 第九層：重要數字與條件

教材出現年齡、年份、數量、百分比、時間、距離、法定門檻、資格條件、程序條件、法律規定時，應特別整理成表：

| 項目 | 數值／條件 | 備註 |
| ---- | ---------- | ---- |
| …    | …          | …    |

有兩個以上相近數字時，必須提醒「這是本章容易混淆的數字」。

## 第十層：概念關係圖

每個主要章節至少建立一張概念關係圖。概念圖必須呈現真正的關係，而不是單純列標題。

樣式一：

```text
A
↓
B
↓
C
```

樣式二：

```text
A
├─ B
│  ├─ B1
│  └─ B2
│
└─ C
   ├─ C1
   └─ C2
```

樣式三：

```text
              核心概念
                  │
        ┌─────────┴─────────┐
        ▼                   ▼
      概念 A              概念 B
        │                   │
      ┌─┴─┐               ┌─┴─┐
      ▼   ▼               ▼   ▼
     A1  A2              B1  B2
```

## 第十一層：一分鐘背誦版

將整章濃縮成考試前可以快速閱讀的內容，優先保留：

- 定義
- 核心差異
- 重要數字
- 分類
- 因果
- 固定項目
- 最容易考的觀念

格式：

```text
概念 A 是……；概念 B 是……；兩者最大的差異是……。
判斷時要注意……。本章最重要的……包括……。
```

一分鐘背誦版應該真正能在短時間內完成複習。

## 第十二層：最終教材透析

最後用一個總結圖把整章壓縮。例如：

```text
              第 X 章核心
                    │
        ┌───────────┴───────────┐
        ▼                       ▼
      身分                     實踐
        │                       │
    ┌───┴───┐              ┌────┴────┐
    ▼       ▼              ▼         ▼
   概念A   概念B          概念C     概念D
```

最後回答「本章真正最重要的核心是什麼？」，用 1～3 句話說明即可。
