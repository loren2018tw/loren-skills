# Textbook Analysis（教材透析）

把使用者提供的教材（課本、講義、Markdown 教材、課文、題目、參考答案、筆記）拆解成結構化知識，而不是摘要：

- 知識骨架、核心概念、概念關係
- 重要定義、判斷關鍵字、考題辨識線索
- 題目解題邏輯、案例考點、易混淆觀念
- 重要數字與條件、快速複習內容

核心精神：不是把課文變短，而是把課文裡真正重要的知識結構透析出來。

## Required context

動筆前先讀 [分析層規格](references/analysis-layers.md)：第四層（概念對比表）到第十二層（最終透析）的格式與範例。輸出前讀 [風格與保真規則](references/style-rules.md)，用其中的十問自檢逐項檢查每個重要知識點，並依三級標記資訊重要性。

## 分析流程

收到教材後依序執行：

1. **掃描結構**：把教材拆成章、節、子概念，畫成樹狀文字圖。目的是找出知識階層，不是重列目錄。完成標準：樹狀圖覆蓋教材所有小節與子概念。

   ```text
   第1章 公民與公民德性
   ├─ 1-1 什麼是公民？
   │  ├─ 國民
   │  └─ 公民
   │      ├─ 廣義公民
   │      └─ 狹義公民
   │
   └─ 1-2 現代公民應具備的基本德性
      ├─ 參與公共事務
      ├─ 遵守法律規範
      ├─ 理性思考批判
      ├─ 和平尊重包容
      └─ 捍衛公平正義
   ```

2. **定核心問題**：列出 2～5 個「讀完本章後學生應能回答」的問題。這些問題必須反映教材真正的學習目標，不要單純複製課本標題。例如：什麼是國民？什麼是公民？國民與公民有什麼差異？現代公民應具備哪些基本德性？
3. **抽取核心概念**：列出本章所有值得單獨透析的概念，一個不漏。完成標準：每個概念都能對應到一個核心問題。
4. **逐概念透析**：每個重要概念套用下方的概念透析模板，七個欄位逐一填寫。
5. **建立概念關係**：標出概念間的上下位、分類、因果、流程、條件、對比關係，用文字圖表示。
6. **轉換為考題辨識方式**：為每個概念建立「關鍵字／情境／行為目的 → 概念」的辨識線索。
7. **透析案例**：教材中的人物、故事、新聞、歷史事件、社會事件、生活情境、圖片案例，逐個拆出考點。
8. **透析題目**：教材附有選擇題、填充題、問答題或參考答案時，分析解題邏輯而非只列答案。
9. **找出陷阱**：主動找出 3～5 個易混淆觀念與易錯點。
10. **整理數字與條件**：年齡、年份、數量、門檻、法律規定等集中成表。
11. **建立整章概念關係圖**：至少一張，呈現真正的關係而非列標題。
12. **製作一分鐘背誦版**：整章濃縮成考前可快速閱讀的版本。
13. **最終透析**：用總結圖壓縮整章，並用 1～3 句話回答「本章真正最重要的核心是什麼」。
14. **輸出存檔**：把透析結果寫成獨立 Markdown 檔案（規則見下方「輸出位置」），完成標準：輸出檔已建立、原始文本未有任何更動。

第四層到第十二層的格式與範例見 `analysis-layers.md`。

## 概念透析模板

每個重要概念依此模板分析：

### 核心定義

用簡潔、準確、學生容易理解的語言說明。把複雜定義轉換成容易理解的形式，但不複製課本原句、不改變原意。

### 判斷關鍵字

列出題目中出現哪些詞語時，應該想到這個概念。例如：

- 國民：國籍、法律身分、具有某國國籍
- 理性思考批判：蒐集資料、查證、比較不同來源、分析不同觀點、思辨資訊

### 核心條件

列出概念成立所需的條件：

```text
條件 A
+
條件 B
+
條件 C
↓
概念成立
```

條件只有一個時，也要明確指出。

### 核心特徵

整理概念最重要的特徵，只保留能幫助理解、判斷或解題的內容。

### 概念關係

概念與其他概念存在上下位、分類、因果、流程、條件或對比關係時，用文字圖表示。例如：

```text
國籍
 ↓
國民
 ↓
達到法定年齡
 ↓
具備參政資格
 ↓
狹義公民
```

### 教材例子

優先使用原教材中的人物、事件、情境或例子。教材沒有例子時，不要自行增加。

### 考題辨識方式

說明選擇題或情境題出現哪些線索時，應該想到這個概念。這是教材透析的重要部分。

## 標準輸出格式

透析結果是一份獨立的透析文件（存成輸出檔），檔首標題為 `第 X 章〈章名〉教材透析`，內容依以下順序輸出：

1. **這一章真正要回答的問題** — 列出 2～5 個核心問題
2. **課文架構** — 用階層式結構整理
3. **核心概念 1、2、…** — 每個概念依模板處理（核心定義、判斷關鍵字、核心條件、核心特徵、概念關係、教材例子、考題辨識方式）
4. **重要概念對比** — 用表格整理真正容易混淆的概念
5. **重要數字／資格／條件** — 集中整理
6. **案例透析** — 分析教材人物、故事與情境的真正考點
7. **題目解題邏輯** — 分析教材題目與選項的判斷方法
8. **最容易出現的陷阱** — 列出重要易錯觀念
9. **整章概念關係圖** — 建立整章知識結構
10. **一分鐘背誦版** — 提供考前快速複習版本
11. **最終教材透析** — 用最精簡的方式指出本章核心

不需要機械套用所有區塊：教材沒有相關內容時，省略該區塊。每個重要知識點依 `style-rules.md` 的十問自檢補全，並標示 ★★★／★★／★ 資訊分級。

## 輸出位置

透析結果一律寫成獨立的 Markdown 檔案，與原始素材分離；絕不把透析內容改寫、附加或合併進原始文本。

- 輸入是檔案：在原始檔同目錄輸出 `<原檔名去附檔名>-透析.md`，例如 `第3課公民.md` → `第3課公民-透析.md`。
- 輸入是貼上文字、多個檔案或沒有檔名：以章節或主題短語命名，例如 `公民第1章-透析.md`。
- 原始檔保持原樣：不編輯、不插入筆記、不加註解。
- 寫檔完成後，在對話中回報：輸出檔位置、產出的區塊清單與 3～5 句重點摘要。完整內容只存在輸出檔中，不要在對話裡重貼全文。
- 使用者只要預覽時，直接在對話顯示內容，不寫檔。
