# 風格與保真規則

資訊重要性分級、內容處理原則、輸出風格、自檢問題與最終目標。分析層格式見 `analysis-layers.md`。

## 資訊重要性分級

主動將資訊分為三級，不要讓所有資訊看起來同樣重要。

### ★★★ 必考核心

- 定義
- 分類
- 核心差異
- 固定數字
- 法律條件
- 核心概念
- 教材明確列出的學習重點

### ★★ 重要理解

- 例子
- 因果關係
- 案例
- 概念應用
- 題目情境

### ★ 補充

- 背景
- 人物故事中的非核心內容
- 延伸資訊

## 內容處理原則

### 保留重要資訊

不要因為整理而刪除：

- 定義
- 法律規定
- 年齡
- 數字
- 專有名詞
- 分類
- 例子
- 題目關鍵條件

### 可以簡化語言，但不能改變原意

原則：

```text
課本語言 → 容易理解的學生語言
```

而不是：

```text
課本內容 → 完全改寫成另一套意思
```

### 不要只做摘要

避免輸出資訊密度不足的內容，例如「本章介紹 A、B、C。A 是……。B 是……。C 是……」。

應進一步回答：

- 怎麼判斷？
- 為什麼？
- 有什麼差異？
- 題目怎麼考？
- 哪裡容易錯？

### 不要過度延伸

資訊不是教材內容時，不要自行加入大量課外知識。確實需要補充時，必須明確標示「補充：」，不要讓學生誤以為補充內容是課本文字。

### 優先使用表格

概念存在明確比較關係時，使用 Markdown 表格。

### 優先使用流程圖

遇到流程、條件、分類、因果、判斷順序時，優先使用文字流程圖。

## 輸出風格

使用：

- 繁體中文
- 臺灣常用教育用語
- 清楚的標題層級
- 高資訊密度
- 簡潔但完整
- 教學導向、考試導向
- 具體說明
- 適度使用表格與文字圖

避免：

- 空泛鼓勵
- 大量複製原文
- 只有答案沒有解釋
- 過度學術化
- 無意義重複
- 所有內容都當作同樣重要
- 為了湊格式加入無關資訊

## 核心判斷問題（十問自檢）

分析每個重要知識點時，依序思考：

1. 這是什麼？ → 定義
2. 有哪些種類？ → 分類
3. 怎麼判斷？ → 判斷條件
4. 有什麼差別？ → 比較
5. 為什麼？ → 原因／目的
6. 會造成什麼？ → 結果／影響
7. 題目怎麼考？ → 題型
8. 哪裡容易錯？ → 易錯點
9. 和其他概念有什麼關係？ → 概念關係
10. 考前最少要記住什麼？ → 一分鐘背誦版

## 最終學習目標

完成教材透析後，學生應該能做到：

- 看到名詞 → 知道定義
- 看到情境 → 知道對應哪個概念
- 看到兩個相似概念 → 知道如何區分
- 看到數字或條件 → 知道代表什麼
- 看到選擇題 → 知道應該找哪些線索
- 看到案例 → 知道案例真正想考什麼
- 看到錯誤敘述 → 知道錯在哪裡
- 考試前 → 可以用一分鐘背誦版快速複習

## 核心精神

教材透析不是把課文重新整理一次，也不是把課文縮短成摘要，而是把課文中的知識結構、概念關係、判斷條件、考題線索與容易犯錯的地方全部透析出來：

```text
課文 → 知識 → 概念 → 關係 → 判斷 → 題目 → 解題 → 複習
```

讓學生不只是「看過課文」，而是能夠：理解 → 分辨 → 判斷 → 解題 → 複習。
