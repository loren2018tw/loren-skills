# doc-to-markdown-with-image 以 Pillow 標注圖內文字、覆蓋式輸出 PNG

群組示意圖（Word 群組：一張底圖＋多個帶座標的文字方塊）經 markitdown 轉出後，底圖抽成媒體資產、圖內文字散落圖下；人類讀者無法把文字對回圖上的位置（agent 讀取不受影響）。決定新增標注步驟：以 Pillow（`ImageDraw`）把圖內文字依原座標、字級、對齊、顏色、直排繪回底圖，直接覆蓋該媒體資產並一律存成 PNG（md 引用同步改副檔名），不留原始底圖檔——重跑轉換即從來源文件重新取得乾淨底圖。單張圖標注失敗（解碼錯誤、找不到可用字型等）只跳過該圖並警告，不中斷整份轉換。

因此本技能是 ADR 0004「純標準庫」的明文例外：腳本可（且必須）依賴 Pillow，缺 Pillow 時以安裝指引失敗；CI 煙霧測試安裝 Pillow 以驗證標注路徑。這是刻意的偏離：若 Pillow 只是選用強化，同一份文件會因機器有無安裝而輸出不同，且「人看得到文字」正是本功能的預設期待。

曾考慮：Pillow 列選用依賴、缺了自動退回現狀（輸出因機器而異，驗收標準浮動）；零依賴的 SVG 標注（檢視器與 agent 讀圖支援不一，風險更高）；維持現狀不標注（痛點無解）。
